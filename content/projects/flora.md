# What does this project actually do ?

The project has been made in Android Studio using Java, Flora is an application that uses image recognition `(teachablemachine.withgoogle)` to identify **flowers from photos**. It features a user friendly interface with access to a database with detailed flower informations. Users can search for flowers, add them to their favorites and create notifications about their next watering and other!
